# Your Character Sheet

A web-based self-reflection tool styled as a life character sheet. It combines the structural wisdom of tabletop RPG character sheets with the rigour of psychological science.

Try it: https://mbthompson.github.io/YourCharacterSheet/

## How to Use

Open the link above, or download `index.html` and open it in any modern browser. There is no server, no build step, and nothing to install.

A first pass takes about twenty minutes. Guided mode walks you through one question at a time. Quick mode puts each section on a single screen, which suits later adjustments.

## Features

- Eight core life attributes, each built from sub-scores on a 1-20 scale
- Big Five personality snapshot (BFI-10)
- Your own list of abilities, active and dormant
- A one-page sheet with a profile chart, expandable detail, and a print layout
- AI prompt generator for a written character study
- Export and import your sheet as a JSON file
- Works on phones as well as desktops

## Data & Privacy

Your sheet stays in your browser's local storage. Nothing is sent to a server. You can export it as a JSON file for backup or to move between devices, and delete it from the browser at any time. The AI prompt contains your scores and profile details, and is only shared if you paste it somewhere yourself.

## Guide

`The Character Sheet - Guide.md` (also provided as a Word document) explains the thinking behind the sheet, the scale, and each attribute in full.
